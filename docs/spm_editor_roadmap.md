# SPM Editor 增量开发路线

> 目标：在保留现有预览能力的基础上，循序完善 SPM JSON 的可视化编辑、导出与新建流程。

## 阶段划分

1. **阶段 0：现状盘点与基线稳固**
   - 清点 `spm` 模块当前覆盖范围（JSON 字段、渲染栈、UI 入口）。
   - 梳理已存在的测试，并补上最小集的回归用例（载入不同方言、动画播放、缺图提示等）。
   - 成果：补充一份《SPM 基线能力报告》，列出缺口清单。

2. **阶段 1：预览体验强化（Milestone A）**
   - 完善图像搜索路径与缓存策略，减少重载开销。
   - 统一坐标换算，支持页面原点/画布缩放的配置化。
   - 新增命中框可视化调试开关、动画步进控制与时间线面板。
   - 成果：`spm-preview.md`（含演示截屏及测试说明）、对应自动化测试。

3. **阶段 2：基础编辑工具（Milestone B-1）**
   - 图层面板：列出 `chipData`，支持选中/锁定/上下移动。
   - 画布操作：现有 chip 的选取、移动、缩放（保持原矩形数据结构）。
   - 新建 chip：从 spritesheet 选择 `srcRect` → 在页面绘制 `dstRect`。
   - 成果：`spm-editor-basics.md`，记录新增交互与 JSON 变更策略；覆盖单元/集成测试。

4. **阶段 3：高级编辑与导出**
   - 命中框编辑（新增、移动、尺寸调整，兼容不同 `shapeType`）。
   - JSON 最小差异导出：保留未修改字段，新增/修改写入 `chipData` 与 `hitRects`。
   - 引入撤销/重做栈，确保编辑可回退。
   - 成果：`spm-editor-advanced.md`，列出最小差异算法与测试用例。

5. **阶段 4：SPM 向导与整体打磨**
   - 向导 UI：逐步录入 `imageData`、`pageData`、初始 chip。
   - 导出配置（目标路径、方言选择、校验提示）。
   - 回归优化：性能 profiling、UX 调整、文档整理、CI 流程补强。
   - 成果：`spm-wizard.md` + 最终《交付手册》。
